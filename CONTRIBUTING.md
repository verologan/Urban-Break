# CONTRIBUTING.md - Guía de Contribución

## 🤝 ¿Cómo contribuir?

Nos encanta recibir contribuciones. Aquí te mostramos cómo hacerlo:

### 1. Fork el proyecto
Crea tu propia copia del repositorio

### 2. Crea una rama
```bash
git checkout -b feature/tu-feature
```

### 3. Haz tus cambios
- Edita los archivos necesarios
- Asegúrate de que el código funcione
- Mantén la consistencia con el estilo existente

### 4. Commit
```bash
git commit -m "Descripción clara de tus cambios"
```

### 5. Push
```bash
git push origin feature/tu-feature
```

### 6. Pull Request
Abre un Pull Request en GitHub describiendo tus cambios

## 📝 Estándares de Código

- Usa nombres descriptivos para variables y funciones
- Comenta secciones complejas
- Mantén la indentación consistente
- Prueba tus cambios antes de hacer commit

## 🐛 Reportar Bugs

Si encuentras un bug:
1. Verifica que no esté reportado
2. Abre un Issue con:
   - Descripción clara del problema
   - Pasos para reproducir
   - Comportamiento esperado vs actual

## 💡 Sugerencias de Mejora

Tus ideas son valiosas:
1. Abre un Issue con la etiqueta "enhancement"
2. Describe la mejora propuesta
3. Explica el valor que aportaría

---

¡Gracias por contribuir! 🙏
